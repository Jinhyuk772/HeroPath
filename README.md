# Hero's Path (용사의 발자취)

젤다 야숨 DLC 의 Hero's Path 처럼, 캐릭터가 어디로 어떻게 걸었는지 **월드맵과 별개인 창**에서
비디오처럼 돌려 본다. 사망 · 레벨업 · 로그인/아웃 · 던전 입장/퇴장 · 귀환석 · 비행 · 퀘스트 완료가 길 위에 표식으로 찍힌다.

## 설치 · 업데이트
- WowUp → **Install from URL** → `https://github.com/Jinhyuk772/HeroPath` (이후 업데이트는 WowUp 버튼 하나)
- 직접 설치: [Releases](https://github.com/Jinhyuk772/HeroPath/releases) 의 zip 을 `Interface\AddOns\` 에 풀기

## 쓰기
- `/hp` 또는 `/heropath` — 창 열기/닫기 (키 설정의 ADDONS 항목에도 있음)
- 위 줄: **캐릭터**(모두 / 한 명) · **지도**(자료가 있는 지역 + 그 대륙 + 던전 층) · **범위**(전체 / 오늘 / 최근 7일 / 세션별)
  · **따라가기**(재생 머리를 화면 가운데에) · **사건**(표식 켬/끔) · **공백 건너뜀**(점이 없는 구간을 재생 때 건너뜀)
- 창 안: 마우스 휠 = 커서 중심 확대/축소, 드래그 = 이동, 오른쪽 아래 손잡이 = 창 크기
- 아래 줄: `>` 재생/정지 · **지금**(실시간 따라가기) · 속도 1x · 10x · 1m/s · 5m/s · 30m/s · 시간 슬라이더(휠로 미세 이동)
- 표식에 마우스를 올리면 누가 · 언제 · 무엇(죽인 몹, 레벨, 던전 머문 시간, 퀘스트 이름 …)
- 캐릭터 드롭다운 옆 색 네모 = 그 캐릭터 선 색 고르기(게임 색 창). `/hp color 초록` · `/hp color <캐릭이름> ff8800` 으로도 됨
- `/hp status` 기록 현황 · `/hp gold <은>` 골드 변화 표식 기준(기본 100은) · `/hp interval <초>` 위치 확인 주기(기본 1초) · `/hp quests` 퀘스트 표식 켬/끔 · `/hp wipe confirm` 전부 지움

## 사건 목록
LOGIN · LOGOUT · DEATH(죽인 몹) · REVIVE · LEVEL · ZONE · FIRST(지역 · 세부 지역 첫 방문) · INST_IN/OUT(머문 시간) · BOSS(던전 보스, ENCOUNTER_END) ·
KILL(희귀 · 희귀 정예 · 월드 보스 처치) · QUEST(완료) · GOLD(기준 이상 골드 변화, 상인/우편/거래/경매 구분) · HEARTH · TAXI_ON/OFF

## 어떻게 기록하나
- 1초마다 `C_Map.GetBestMapForUnit` + `GetPlayerMapPosition`. 움직였을 때만(지도의 12/10000 이상) 점을 찍는다 → 4시간 플레이 ≈ 1만 점 정도.
- 저장은 **기록한 지도의 좌표 그대로**. 보는 지도가 다르면 `GetWorldPosFromMapPos → GetMapPosFromWorldPos` 로 그 지도 위에 다시 놓는다.
  타일도 그 지도의 월드맵 에셋(`GetMapArtLayerTextures`)을 직접 깔기 때문에 어떤 배율에서도 발자취가 에셋과 어긋나지 않는다.
- 던전: Forever 클라이언트의 UiMap 표(60개)에는 던전 지도가 없고 인스턴스 안에선 UnitPosition 도 막혀 있어 **좌표는 못 얻는다**
  (`state/maps/db2/UiMap.csv` 로 확인). 대신 입장 표식에 안에서 생긴 일(세부 구역 이동 · 보스 · 희귀 처치 · 사망 · 부활 · 레벨 · 퀘스트 · 골드)이
  시간순 목록으로 붙고 머문 시간이 남는다. 층 지도가 있는 클라이언트라면 밖과 똑같이 기록된다.
- 로그아웃 · 귀환석 · 순간이동처럼 3분 넘게 끊긴 구간은 선을 잇지 않는다. 비행 중 선은 반투명, 유령 상태는 회색.
- 세션(로그인~로그아웃)마다 한 묶음. 계정 공용 SavedVariables(`HeroPathDB`) 라 같은 계정의 모든 캐릭터가 한 창에 색 다르게 겹쳐 보인다.

## 둘이 보기 (0.3.0)
양자 동의 뒤에만 발자취가 오간다. 명령으로 상대를 지정하는 방식이 아니라 **초대 → 상대 수락**이다.
- 설정(ESC → 옵션 → AddOns → Hero's Path) 의 "둘이 보기" 에서 이름을 적고 초대, 또는 플레이어를 대상으로 잡고 "대상 초대". 명령은 `/hp invite <이름>`.
- 상대 화면에 수락/거절 창이 뜬다(채팅에도 안내). 수락하면 양쪽 설정에 짝이 저장되고, 그때부터 서로의 점·사건이 양쪽 `HeroPathDB` 에 쌓인다. 어느 쪽이든 "해제" 로 끊을 수 있고, 받아 둔 발자취는 남는다(`/hp forget <이름>` 으로 지움).
- 조건: 같은 서버 · 같은 진영 · 둘 다 이 애드온. 캐릭터 단위로 짝을 맺는다(부캐는 따로 초대).
- 전송: 애드온 귓속말(`HeroPath` 접두어), 메시지당 점 9개, 0.15초 간격. 접속 중이면 2초마다 새 점을 보내고, 접속할 때 서로 세션 목록(시작·점 수·사건 수)을 비교해 빠진 구간만 받아 채운다. 한쪽이 꺼져 있던 동안의 기록은 다음에 둘 다 접속했을 때 보충된다.
- 짝이 아닌 사람이 보낸 자료는 버린다. "초대 받기" 를 끄면 아무도 초대할 수 없다.
- 안 보내는 것: 던전 입구 표식에 붙는 안쪽 사건 목록(log). 좌표가 없는 던전 안 구간은 원래 점이 없다.

## 시험
`python -I -X utf8 tools/heropath_synctest.py` — 클라이언트 둘(Lua 런타임 둘)에 애드온 귓속말을 중계해 초대 → 수락 → 실시간 전송 → 재접속 보충 → 제3자 거부 → 해제를 검사한다.
`python -I -X utf8 tools/heropath_smoketest.py` — 스텁 위에서 로그인 → 걷기 → 레벨업 → 던전 → 사망 → 귀환석 → 로그아웃을 흘려 보내고
사건 · 점 · 던전 머문 시간 · 뷰어(지도 후보, 재생 끝까지, 휠 확대, 대륙 지도 변환 좌표)를 검사한다.
